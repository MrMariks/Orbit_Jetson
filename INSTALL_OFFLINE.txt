Установка Orbit_Jetson на другом ПК (офлайн или с папкой offline_packages)
=============================================================================

1. Скопируйте на другой ПК всю папку проекта Orbit_Jetson (вместе с папкой offline_packages).

2. На том ПК установите Python 3.8–3.11 (если ещё не установлен).
   https://www.python.org/downloads/

3. Откройте терминал (cmd или PowerShell) в корне проекта Orbit_Jetson.

4. Создайте виртуальное окружение (рекомендуется):
   python -m venv venv
   venv\Scripts\activate

5. Установите зависимости из папки offline_packages (без интернета):
   pip install --no-index --find-links=offline_packages -r requirements.txt

   Если появится ошибка про пакет modelhub-client (git) — один раз подключите интернет и выполните:
   pip install git+https://github.com/ria-com/modelhub-client.git
   затем снова: pip install --no-index --find-links=offline_packages -r requirements.txt

   Либо установите всё с интернетом: pip install -r requirements.txt

6. Запуск приложения:
   python -m orbit_jetson.main

7. На другом ПК настройте при необходимости:
   - orbit_jetson/config.py (BACKEND_URL, CAMERA_INDEX и др.)
   - orbit_jetson/api_key.txt (API-ключ)
