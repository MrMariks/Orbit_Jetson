# Orbit_Jetson

Патрульный модуль для устройства **Nvidia Jetson**: отдельное клиентское приложение с камерой, распознаванием номеров (ALPR nomeroff-net) и отправкой данных на **Orbit_Backend**.

## Технологии

- **Python** — основной язык
- **PyQt5** — графический интерфейс
- **folium** — карта (отображение в QWebEngineView)
- **OpenCV** — захват и обработка видео с камеры
- **nomeroff-net** — ALPR (детекция рамки номера, выравнивание, OCR под СНГ/РК)

## Структура проекта

```
orbit_jetson/
├── __init__.py
├── main.py          # Точка входа
├── ui.py            # Окно PyQt5: видео, номера, карта, кнопки
├── camera.py        # Камера + ALPR (nomeroff-net), отправка детекций
├── gps.py           # Заглушка GPS (Павлодар/Актау)
├── api_client.py    # Отправка телеметрии и детекций на бэкенд
└── config.py        # Настройки (API_TOKEN, BACKEND_URL и др.)
```

## Быстрый старт

### С другого ПК (клонирование с GitHub)

```bash
git clone https://github.com/<ваш-логин>/Orbit_Jetson.git
cd Orbit_Jetson

python -m venv venv
# Windows:
venv\Scripts\activate
# Linux/macOS:
source venv/bin/activate

pip install -r requirements.txt
```

Создайте файл с API-ключом:

- Скопируйте `orbit_jetson/api_key.txt.example` в `orbit_jetson/api_key.txt`.
- Откройте `api_key.txt` и замените содержимое на ваш ключ из Orbit_Backend (одна строка).

При необходимости отредактируйте `orbit_jetson/config.py`: **BACKEND_URL**, **CAMERA_INDEX**.

Запуск:

```bash
python -m orbit_jetson.main
```

В окне нажмите **«Старт мониторинга»**.

## Функционал

- **Видеопоток** — отображение с камеры в реальном времени, рамки вокруг распознанных номеров.
- **Распознанные номера** — список последних номеров; детекции (номер + фото) отправляются на `POST /api/v1/detect`. Повторы одного номера не шлются 12 часов.
- **Карта** — позиция по GPS (TCP NMEA с телефона или координаты по умолчанию).

## API Backend

- **POST /api/v1/detect** — JSON: `plate_text`, `full_image`, `crop_image` (base64). Заголовок: `Authorization: Bearer <API_TOKEN>`.
- **POST /api/v1/patrol/telemetry** — JSON: `license_plate`, `timestamp` (при необходимости).

## Передача геолокации с телефона (постоянное отображение на карте)

### Вариант А: через браузер (без приложений)

Для запроса геолокации браузер на телефоне требует **HTTPS**. По умолчанию сервер запускается по HTTPS с самоподписанным сертификатом (при первом запуске создаётся через `openssl`, если он установлен).

1. Телефон и ПК подключены к **одной Wi‑Fi сети**.
2. В `orbit_jetson/config.py`: **`GPS_HTTP_PORT = 8766`**, **`GPS_HTTP_USE_HTTPS = True`** (порт 0 = выключено).
3. Запустите ПО на ПК: `python -m orbit_jetson.main`, нажмите **«Старт мониторинга»**. В консоли: `GPS HTTP: приём координат на порту 8766 (HTTPS)`.
4. Узнайте **IP-адрес ПК** в этой Wi‑Fi (`ipconfig` в cmd — IPv4, например `192.168.8.194`).
5. **На телефоне** откройте в браузере ссылку: **`https://IP_ПК:8766/`** (например `https://192.168.8.194:8766/`).
6. Браузер покажет предупреждение о самоподписанном сертификате — нажмите **«Дополнительно»** → **«Перейти на сайт»** (или аналогично). Затем разрешите доступ к геолокации — координаты отправятся на ПК, на карте появится ваша точка. Чтобы обновить позицию — снова откройте ссылку или обновите страницу.

Если на ПК нет `openssl` в PATH, сервер запустится по HTTP и на телефоне геолокация может не запрашиваться. Установите OpenSSL или укажите путь к готовым `cert.pem` и `key.pem` в **`GPS_HTTP_CERT_DIR`**.

---

### Вариант Б: постоянная передача (приложение NMEA по TCP)

ПО подключается к телефону по Wi‑Fi и читает поток NMEA — позиция обновляется непрерывно.

### Шаг 1: Телефон и ПК в одной Wi‑Fi сети

Убедитесь, что телефон и компьютер в одной локальной сети (один роутер).

### Шаг 2: Приложение на телефоне (режим TCP‑сервер)

На телефон нужно поставить приложение, которое раздаёт GPS в формате NMEA по TCP в режиме **сервера** (принимает подключение с ПК).

**Варианты:**

- **Share GPS** (Android) — [jillybunch.com/sharegps](https://www.jillybunch.com/sharegps/nmea-tcp.html): режим «Server», укажите порт (например **11123**). Разрешите приложению доступ к геолокации и отключите для него оптимизацию батареи, чтобы работало в фоне.
- **gpsdRelay** (Android, F-Droid) — раздаёт NMEA по TCP/UDP.
- Любое другое приложение, которое в режиме TCP‑сервера шлёт строки NMEA (`$GPRMC`, `$GPGGA` и т.п.) на указанный порт.

Запустите приложение и включите трансляцию (сервер слушает порт).

### Шаг 3: Узнать IP телефона

На телефоне: **Настройки → Wi‑Fi → текущая сеть** (или «Дополнительно») → **IP‑адрес**.  
Например: `192.168.1.50`.

### Шаг 4: Настройка в ПО

В `orbit_jetson/config.py` укажите:

- **PHONE_IP** — IP телефона в Wi‑Fi (как в шаге 3), например `"192.168.1.50"`.
- **GPS_PORT** — порт, на котором слушает приложение на телефоне (например **11123**).

Перезапустите приложение (`python -m orbit_jetson.main`). После нажатия «Старт мониторинга» ПО подключится к телефону и начнёт обновлять позицию на карте. Если подключиться не удаётся, на карте останутся координаты по умолчанию (**DEFAULT_LAT**, **DEFAULT_LON**).

---

В `gps.py` реализован TCP‑клиент: он подключается к телефону и парсит NMEA; при недоступности телефона используются координаты по умолчанию из config.
